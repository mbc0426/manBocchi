Markdown 的好处，是可以先专心写内容，再用少量符号表达结构。这篇示例展示了笔记页的目录、引用、列表和代码复制。

## 用标题建立层次

文章标题由页面自动显示，正文从二级标题开始。每个二级标题最好回答一个独立的问题。

```markdown
## 我想解决什么问题

先用一段话说明背景。

### 第一步

写下具体的操作或观察。
```

## 用列表整理步骤

当内容存在明确顺序时，用有序列表：

1. 写下问题，不急着寻找答案。
2. 记录尝试过的方法和得到的结果。
3. 用自己的话总结最有用的发现。

当信息只是并列关系时，用无序列表：

- 需要继续阅读的资料。
- 还没有验证的想法。
- 下次可以尝试的方向。

## 留下代码和引用

技术内容可以使用代码块。右上角的复制按钮可以一次复制整段内容。

```javascript
const notes = ['观察', '尝试', '记录'];

for (const note of notes) {
  console.log(`今天的小进步：${note}`);
}
```

> 好的笔记不一定完整，但应该让未来的自己看得懂。

## 写完之后再整理

第一遍可以松散一点。写完后再检查标题是否清楚、段落是否太长、例子是否能解释问题。

只保留真正帮助理解的格式，就足够了。
